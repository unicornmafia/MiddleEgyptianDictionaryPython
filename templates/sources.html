About This Project

Seba-Seba Egyptian Dictionary is a reconstruction of and tribute to the Middle Egyptian Dictionary web application. That project is a remarkable resource for students and scholars of Middle Egyptian, and this work would not exist without the effort that went into building it. Many thanks to its creators.

The dictionary data in this project was drawn from the same sources used by the original application, supplemented by additional wordlists and grammar references listed below.

Dictionary Sources

  • A Concise Dictionary of Middle Egyptian (1991) — Raymond O. Faulkner. PDF. Link
  • A Concise Dictionary of Middle Egyptian (Revised edition) — Raymond O. Faulkner, revised by Boris Jegorovic. PDF. Link
  • Middle Egyptian Dictionary (2018) — Mark Vygus. PDF. Link
  • Middle Egyptian Dictionary (2012) — Mark Vygus. PDF. Earlier edition; included for reference.
  • Dictionary of Middle Egyptian (2006) — Paul Dickson. PDF. Link
  • OpenGlyp Lexicon — Morris Franken. Sign-indexed wordlist from the OpenGlyp project (Lexicon.txt), providing corpus-frequency data used for sign variant ranking.
  • How to Read Egyptian Hieroglyphs — Mark Collier & Bill Manley. Wordlist imported from HieroWords (Collier&Manley.hrw).
  • Middle Egyptian: An Introduction to the Language and Culture of Hieroglyphs — James P. Allen. Vocabulary imported from HieroWords (Allen Lessons 1–8.hwd).
  • Middle Egyptian Grammar — James E. Hoch. Vocabulary imported from HieroWords (Hoch 1–2.hwd).
  • The Cosmos of Khnumhotep II at Beni Hassan — Janice Kamrin. Glossary data compiled from community contributions (kamrin_chapters_1-2, kamrin_pages_31-128, kamrin_34-38-67-69, kamrin_titles).
  • Biliteral and Triliteral sign wordlists — HieroWords community. Imported from Biliterals in English.hrw and Triliterals in English.hrw. HieroWords download page
  • Gardiner's Grammar sign list — Egyptian hieroglyph sign data derived from Gardiner’s Egyptian Grammar.

Software & Libraries

  • RES (Rendering of Egyptian Signs) — Mark-Jan Nederhof. The JavaScript library used to render hieroglyphs in the browser. RES source
  • HieroWords — Wordlist management application whose export format was used for several of the dictionary files above. HieroWords download page

This Project

Seba-Seba Egyptian Dictionary is an open-source reconstruction. The source code is available on GitHub. Contributions, corrections, and additional wordlists are welcome.
